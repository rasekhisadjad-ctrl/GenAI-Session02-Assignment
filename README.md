## محدودهٔ تحویل

PDF پیوست پنج سؤال تحلیلی دارد و پروژهٔ عملی مستقل تعریف نکرده است. بخش محاسباتی سؤال دوم به‌صورت مثال اجرایی پیاده شده است. انتخاب Python برای نمایش محاسبات و نرخ یادگیری ۰٫۰۰۱، تصمیم‌های توضیحی این تحویل هستند.

در مثال سؤال دوم، `x=10`، `w=2` و مقدار واقعی `30` است. پیش‌بینی اولیه `20`، زیان اولیه `100` و گرادیان `-200` می‌شوند. بعد از یک گام، وزن `2.2`، پیش‌بینی `22` و زیان `64` هستند.

## اجرای نمونه و بررسی

Python 3.10 یا بالاتر کافی است. کد از کتابخانهٔ استاندارد استفاده می‌کند.

```bash
python gradient_demo.py
python -m unittest discover -s . -v
```
